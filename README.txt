ATELIER — fixed package

Open index.html (double-click). Every page is fully self-contained:
CSS, JavaScript and images are built INTO each .html file, so the site
can no longer lose its styling or photos when folders get separated.

Keep the five pages in the same folder so the navigation links work:
index.html, pieces.html, wardrobe.html, quiz.html, about.html

Online: Google Fonts, live FX rates, weather and partner catalogue load.
Offline: the site falls back to system fonts and built-in data.
